# Micro Shop Metrics Dashboard

A small, dependency-free dashboard for checking the health of a neighbourhood or online shop. It summarises recent revenue, order volume, average order value, returning customers, and recent orders from realistic seed data.

## Run locally

Open `index.html` in a modern browser, or serve the folder with any static file server.

## Validate

```bash
npm test
npm run check
```

The project intentionally uses plain HTML, CSS, and JavaScript so it is easy to understand and extend.
